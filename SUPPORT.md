# Support

MCP Warden is an open source project. Support is best-effort unless a separate support agreement exists.

## Before Asking for Help

Please check:

- [README.md](README.md)
- [docs/CLI.md](docs/CLI.md)
- [docs/POLICY.md](docs/POLICY.md)
- [docs/OPERATIONS.md](docs/OPERATIONS.md)
- Existing issues and discussions, if enabled

## Good Bug Reports

Include:

- MCP Warden version or commit.
- Node.js and npm versions.
- Operating system.
- Command you ran.
- Expected behavior.
- Actual behavior.
- Relevant logs with secrets removed.
- Minimal policy file or MCP config needed to reproduce.

## Security Issues

Do not report private vulnerabilities in public issues. Use [SECURITY.md](SECURITY.md).

## Feature Requests

For feature requests, explain:

- The workflow you are trying to support.
- Why current commands or policy options are insufficient.
- Any security implications.
- Whether you can help test the change.
